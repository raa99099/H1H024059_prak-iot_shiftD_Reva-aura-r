Daftar Percobaan
Percobaan 1A — Akuisisi Data Sensor DHT Membaca suhu dan kelembaban dari sensor DHT11 setiap 2 detik dan menampilkannya ke Serial Monitor.
Percobaan 2A — Kendali Aktuator Relay Berdasarkan Data Sensor Mengendalikan relay/LED berdasarkan pembacaan suhu dan nilai ambang batas (threshold).

Setiap folder percobaan berisi kode program (.ino) beserta README masing-masing yang memuat: deskripsi program, konfigurasi rangkaian, hasil pengamatan, dan analisis kesesuaian dengan spesifikasi modul.

Catatan Penyesuaian Alat

Sensor yang tersedia di sesi praktikum ini adalah DHT11, bukan DHT22 seperti pada modul. Perubahan hanya pada baris DHTTYPE; struktur logika program tetap mengikuti modul.
